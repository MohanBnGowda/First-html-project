📚 Tech Glossary

HTML
HTML, or HyperText Markup Language, is the standard markup language used to create and structure web pages. It forms the backbone of almost every website on the internet, defining the content and organization of information displayed in a web browser.
CSS
CSS, or Cascading Style Sheets, is a stylesheet language used to describe the presentation of web pages written in HTML or XML. It is a fundamental technology for web development, working alongside HTML (which provides structure and content) and JavaScript (which adds interactivity).
js
JavaScript (JS) is a high-level, dynamically typed programming language primarily known for its role in creating interactive and dynamic content on websites. It is one of the core technologies of the World Wide Web, alongside HTML and CSS.
REACT
React, often referred to as React.js or ReactJS, is a JavaScript library for building user interfaces (UIs). Developed and maintained by Meta (formerly Facebook) and a large open-source community, React focuses specifically on the view layer of web applications, allowing developers to create interactive and dynamic UIs.
